## Guardrails Ringkas

1. **1 step = 1 commit** → test → review → stop
2. **Scope = roadmap only** → temuan lain = catat, jangan fix
3. **No behavior change** → characterization test dulu
4. **Crypto I/O frozen** → persetujuan eksplisit kalau ubah
5. **No new deps** → stdlib only (tooling Phase D2 only)
6. **UI via widgets only** → no print/input/ANSI/divider manual di fitur
7. **Bahasa Indonesia** untuk penjelasan, English untuk code

---

## Security Non-Negotiable

- `hmac.compare_digest()` untuk semua verify
- `secrets` untuk random crypto values
- Warning MD5/SHA1/ECB/RC2 di UI
- No secrets in logs/history/error messages
- Generic error messages (no padding oracle)
